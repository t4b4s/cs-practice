Git — это система контроля версий, которая работает локально на компьютере.
GitHub — это онлайн-сервис для хранения Git-репозиториев и совместной работы.
Git может работать без GitHub, а GitHub без Git — нет.

##Использованные команды

git status — показывает текущее состояние репозитория: какие файлы изменены,
какие добавлены в индекс, какие ещё не отслеживаются.

git diff — сравнивает рабочую папку с индексом. Показывает изменения,
которые ты сделал на диске, но ещё не добавил через git add.

git diff --staged — сравнивает индекс с последним коммитом. Показывает,
что уже подготовлено и попадёт в следующий коммит.

##Ветки

Ветка — это подвижный указатель на коммит. Она не копирует файлы, а просто
ссылается на определённый коммит в истории. Главная ветка обычно называется main.

При новом коммите ветка, в которой мы находимся, передвигается вперёд —
начинает указывать на новый коммит. Остальные ветки остаются на своих местах.
Поэтому изменения, сделанные в одной ветке, не видны в другой, пока их не сольют.

Слияние (merge) переносит изменения из одной ветки в другую. При слиянии
создаётся коммит слияния, у которого два родителя: последний коммит текущей
ветки и последний коммит вливаемой ветки. С флагом --no-ff коммит слияния
создаётся всегда, поэтому в истории остаётся видимый след ветки.
