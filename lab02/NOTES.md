Git — это система контроля версий, которая работает локально на компьютере.
GitHub — это онлайн-сервис для хранения Git-репозиториев и совместной работы.
Git может работать без GitHub, а GitHub без Git — нет.

Использованные команды
git status — показывает текущее состояние репозитория: какие файлы изменены,
какие добавлены в индекс, какие ещё не отслеживаются.

git diff — сравнивает рабочую папку с индексом. Показывает изменения,
которые ты сделал на диске, но ещё не добавил через git add.

git diff --staged — сравнивает индекс с последним коммитом. Показывает,
что уже подготовлено и попадёт в следующий коммит.
